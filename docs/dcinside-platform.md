# 디시인사이드 플랫폼 사실

코드가 기대는 디시 쪽 동작. 관측 날짜를 붙인다 — 디시가 바꾸면 낡는다.

## 목록 페이지 파싱

- 목록 행: `<tr data-no> … gall_tit … <a>` (`background.js` 정규식)
- 제외: `icon_notice`(공지), `icon_fnews`(뉴스). 대상은 `icon_txt`, `icon_pic`만
- 망호 판별(content): `.ub-content` 행의 `.gall_subject` 텍스트가 `헬망호`
- 말머리 선택(글쓰기): `li[data-val="헬망호"]`

## 글쓰기 에디터

- note(summernote) 기반. 툴바 `.note-toolbar`, 본문 `.note-editable`, 제목 `input[name=subject]`
- 확장 CSS는 에디터 안에 적용되지 않는다 → 인라인 스타일만

## 저장 시 HTML 새니타이즈 (2026-02 관측, 2026-09 업데이트 이후 재검증 필요)

- 인라인 `style`이 있는 `<a>`는 `href`가 삭제됨
- `display:inline-block`, `border-radius` 제거
- FE0F가 `+`로(☄️ → `☄+`), 일부 이모지가 `?`로(🤖 🪳 🦑 🗺️ 추정, 개별 미검증)
- 당시 보존된 이모지: 🚀 🌠 🏭 🐜 🐛 👾 👽 💎 💴 💵 💷 📍 ❓ ❔
- `class`만 있고 style 없는 `<a href="steam://…" class="seaf-join-button">`가 href·☄️ 보존된 채 저장 HTML에 있었음 — 어떤 경로로 저장됐는지 미검증
- 에디터 안 버튼 방식은 **포기**. 버튼은 조회 페이지에서 `convertLobbyLinks`가 만든다

### 규칙 — 유니코드 버전이 아니라 코드포인트 범위

출처: `https://gall.dcinside.com/_js/dccon/txtcon.js?v=260909` (글자콘 클라이언트 필터).
주석상 서버 `Dctemplate::make_txtcon`과 같은 규칙. **본문·제목 서버 필터는 코드로 확인 불가 — 같은 계열로 추정.**

- 이모지 범위: `U+1F000–1FAFF`, `U+2600–27BF`, `U+2B00–2BFF`
- 범위 밖 4바이트 문자 → `+`
- `FE0F`(변형선택자)는 직전 글자가 이모지 범위일 때만 유지 (mobile 규격)
- 글자콘 deny: `FE0F`, `200B–200F`, `20E3`(키캡), 국기 `1F1E6–1F1FF`, 피부색 `1F3FB–1F3FF`
- 규격 `charset_mode: 'wide' | 'mobile'` 두 벌 존재, 관측 시 `wide`

### 관측과 대조

| 입력 | 결과 | 설명 |
|---|---|---|
| `❗` U+2757 | 정상 | 범위 안 + 기본 이모지 표시 |
| `‼️` `⁉️` U+203C/2049 | `‼+` `⁉+` | 범위 밖 → FE0F 불인정 (본문에선 `+` 치환으로 보임, 추정) |
| `♥️` U+2665 | 정상 | 2600 범위 → FE0F 유지 |
| `🩷` U+1FA77 | 정상 | 범위 안 |
| `☄` U+2604 흑백 | — | 기본 텍스트 표시 문자. FE0F 없으면 Windows에서 흑백 글리프. 업데이트 후 재검증 |
| `🤖🦑` → `?` | — | 업데이트 전 관측. 지금은 범위 안 → 재검증 |

### SEAF 규칙

- 제목·본문에 들어가는 이모지(`tags.js` 포함)는 위 세 범위 안에서만 고른다
- 피할 것: `2000–25FF` 문자 + FE0F(‼ ⁉ ™ © ® ▶ ↗ 등), 피부색, 국기, 키캡
- 확장이 화면에만 그리는 UI(토스트, 목록 버튼)는 저장되지 않으므로 제약 없음
